# Poprawa kolokwium — fragment kodu API

Fragment projektu z poprawy kolokwium APBD: kontroler klientów, DTO samochodów i serwis bazy danych. Repozytorium nie zawiera pliku .csproj, .sln ani Program.cs, więc nie jest samodzielną aplikacją do uruchomienia.

**Kategoria:** fragmenty kodu do kolokwiów · **Przedmiot:** APBD · **Rok akademicki:** 2024/2025

## Technologie

C#.

## Gdzie jest kod

- `KolokwiumPoprawa/KolokwiumPoprawa/Controllers/` — kontroler klientów.
- `KolokwiumPoprawa/KolokwiumPoprawa/Models/` — DTO klientów i samochodów.
- `KolokwiumPoprawa/KolokwiumPoprawa/Services/` — interfejs i implementacja serwisu bazy danych.

## Status

To zbiór plików źródłowych, bez kompletnej konfiguracji projektu. Nie ma samodzielnego polecenia uruchomienia. Pełniejszy projekt o podobnej tematyce znajduje się w [repozytorium Poprawa](https://github.com/Michlean30495/Poprawa).
